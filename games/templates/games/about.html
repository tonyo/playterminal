About PlayTerminal

PlayTerminal is an experimental project which aims at bringing nice old-school terminal/console games back to life. And where? Right in your browser! Each game runs in a tiny Alpine Linux virtual machine, emulated right in the page by v86 and shown in an xterm.js terminal. Nothing runs on our server: once the page has loaded, the game is all yours.


Created by tonyo (aka Anton Ovchinnikov): GitHub, Keybase

This project is open source. Fork'n'knife on GitHub; the third-party licenses are on the Licenses page.
